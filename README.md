## 🛠 Tech Stack

- **Backend:** Python + Flask
- **AI:** Groq API (Llama 3.3 70B)
- **Frontend:** HTML / CSS / JavaScript
- **Hosting:** Render.com (free tier)

## 🔐 Setup

Create a `.env` file:
```env
GROQ_API_KEY=your_key_from_console.groq.com
```

Run locally:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py
```
